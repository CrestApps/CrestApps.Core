# Version 1.3.0 Release Notes

**Package version**: `1.3.0`

**Release date**: 2026-08-27

## Change Logs

- Added support for messages on MCP server prompts, so a prompt can define an ordered set of role-tagged messages, with create and edit UI in both the Razor Components and MVC admin hosts.
- Fixed the AI Chat SignalR hub to authorize the caller against the target session's profile before dispatching notification action handlers, so a caller can no longer act on an arbitrary session id.
- Fixed the AI chat session close cycle so a session whose post-close attempt budget is exhausted is marked terminally failed only once; a session that is no longer pending is no longer re-queued, re-saved, and re-logged on every subsequent cycle.
